## 4. Decisions Made

1. **`deleteAllData()` resets onboarding flag to `false`** — When a user deletes all their data, the onboarding-complete flag in DataStore is also reset. This means on the next app launch, they go through onboarding again and set up their profile fresh. The alternative was to keep the profile and only delete logs, but the team decided a full reset is cleaner and matches user expectations of "delete everything".

2. **`finishAffinity()` after delete** — After data deletion, the app closes entirely rather than returning to Home. Reason: if the app stayed open, all the LiveData observers would fire with null data and the UI would be in an undefined state. Closing and relaunching is the safe path.

3. **Touch event returns `true` for all actions in SheetCalendarView** — Not just for `ACTION_UP`. If `ACTION_DOWN` returns false, Android's event system assumes this View is not interested in the touch sequence and stops delivering further events to it. Returning `true` on `ACTION_DOWN` claims the touch, which ensures `ACTION_UP` arrives correctly so the date selection can fire.
